# Yumdown Project Skills

These project-local skills provide focused instructions derived from [`implementation.md`](../../implementation.md). Zed can discover skills in `.agents/skills/`; each skill has its own `SKILL.md` and can be loaded when its description matches a task.

- [`wails-go-backend`](wails-go-backend/SKILL.md) — Wails contracts/events, Go services, queue lifecycle, subprocess safety, and persistence.
- [`yt-dlp-media-tools`](yt-dlp-media-tools/SKILL.md) — tool resolution/distribution, safe invocation, progress, output verification, and media-specific tests.
- [`react-atomic-ui`](react-atomic-ui/SKILL.md) — Base UI, atomic React organization, Wails bindings, accessibility, and frontend validation.
- [`cross-platform-release`](cross-platform-release/SKILL.md) — OS/architecture targets, packaging, CI, release risks, and smoke-test evidence.
